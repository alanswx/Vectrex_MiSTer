# Vectrex Artwork

Vectrex artwork represents the translucent plastic sheet placed in front of
the tube. The core treats it as a transmissive overlay: vectors are tinted by
the artwork, while Overlay Brightness controls the artwork's base visibility.

## Install and Automatic Loading

Copy the desired `.art` file beside its game ROM in
`/media/fat/games/Vectrex/`. Automatic loading requires the artwork and
ROM to have exactly the same basename:

```text
Mine Storm.vec
Mine Storm.art
```

The same rule applies to `.bin` and `.rom` files. Artwork can also
be selected manually through **Load Overlay** in the core menu.

The unsuffixed package is for Normal orientation. Packages ending in `_90CW`
or `_90CCW` are prepared for the corresponding quarter-turn orientation. Copy
or rename the desired orientation package to the ROM basename when it
should load automatically.

`artwork/generated/` contains prepared packages for 163 titles in all three
orientations.

## Requirements

- Python 3.10 or newer
- [Pillow](https://pillow.readthedocs.io/)

Install Pillow with:

```text
python -m pip install Pillow
```

Run the commands below from the repository root.

## Package Layout

Each `.art` file is a VART container with four independently compressed
planes. Every plane is a complete renderer raster, including transparent
margins. The core selects an exact width and height and performs no resizing,
centering, or rotation.

| File | Dimensions |
| --- | --- |
| `1080p.png` | 1360x1080 |
| `720p.png` | 916x720 |
| `480p.png` | 720x480 |
| `240p.png` | 720x240 |

480p and 480i share the 720x480 plane. Input PNGs may be RGBA or indexed. The
packer preserves alpha, quantizes the image to at most 255 colors, and chooses
a 4-, 6-, or 8-bit palette from the resulting color count.

Each package represents one screen orientation. Orientation is encoded by the
selected filename rather than VART metadata, keeping the display-time RTL
identical for every orientation.

## One Orientation

Place the four required PNGs in one directory, then run:

```text
python artwork/build_vart.py pack INPUT_DIR game.art
```

The command rejects missing or incorrectly sized inputs. It verifies every
encoded row, the complete decoder round trip, and the container CRC before
replacing the destination.

## All Orientations

Prepare eight authored PNGs:

```text
game_artwork/
  normal/
    1080p.png
    720p.png
    480p.png
    240p.png
  90CW/
    1080p.png
    720p.png
    480p.png
    240p.png
```

`90CW` means rotated 90 degrees clockwise when facing the display. Build all
three packages with:

```text
python artwork/build_vart.py pack-all game_artwork --name minestorm -o artwork/generated
```

This produces:

```text
minestorm.art
minestorm_90CW.art
minestorm_90CCW.art
```

The counter-clockwise package is generated by rotating each authored clockwise
plane by 180 degrees. That operation is exact and adds no resampling.

The unsuffixed package is the normal orientation. A rotated package can be
loaded manually or renamed to the ROM basename when that orientation should
load automatically.

## ROM-Name Copies

Automatic loading expects an artwork file with the same basename as the ROM.
Create a text file containing one ROM filename per line, then generate a copy
script with:

```text
python artwork/name_for_roms.py --roms roms.txt --art artwork/generated --sh copy_artwork.sh
```

The tool normalizes title punctuation, reports ambiguous names, and never
guesses when more than one package could match.

## Legacy Packages

Convert one legacy VART package with:

```text
python artwork/build_vart.py migrate old.art -o OUTPUT_DIR
```

Convert a directory with:

```text
python artwork/build_vart.py migrate-all INPUT_DIR -o OUTPUT_DIR
```

Migration extracts the centered content from each available legacy plane and
reframes it at the current renderer dimensions. Existing quarter-turn planes
are retained. When absent, 90CW is derived from the normal plane and 90CCW from
90CW. New artwork should use separately authored normal and 90CW inputs.

VART storage is limited to four MiB by the reserved DDRAM region. The packer
leaves the destination unchanged if a package exceeds that limit or fails any
validation check.
