# Low-resolution and missing overlay search list

The working baseline is 846x1080 source art. Higher resolution is welcome but
not required; source fidelity, dark vector playfield, and correct alpha matter
more. Please look for original PNG/TIFF/PSD scans where possible, not screenshots
with game vectors burned in.
