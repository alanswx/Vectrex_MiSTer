# Alpha spot-check sheets

Each canonical overlay is shown six times against solid black, white, red,
green, blue, and gray backgrounds. Color changes around the artwork make
partial transparency, halos, and accidentally opaque regions easier to see.

- [Black background](canonical_alpha_000000.png)
- [White background](canonical_alpha_ffffff.png)
- [Red background](canonical_alpha_ff0000.png)
- [Green background](canonical_alpha_00a000.png)
- [Blue background](canonical_alpha_0000ff.png)
- [Gray background](canonical_alpha_808080.png)
- [Downloaded/reference assets on gray](downloaded_references_gray.png)

The canonical source images are all RGBA PNGs. The `mean` alpha values in the
research notes are image-wide averages, not a pass/fail judgment; visual
inspection is still needed for edge quality and intended translucency.
